# JA Pinturas - Website Oficial

Website institucional e landing page da **JA Pinturas**, especializada em serviços de pintura residencial, predial, comercial e efeitos decorativos de alto padrão.

## 🚀 Tecnologias Utilizadas

- **HTML5 Semântico**
- **CSS3 Moderno** (Flexbox, CSS Grid, Custom Properties, Glassmorphism)
- **JavaScript Vanilla** (Interatividade, Menu Responsivo, Integração WhatsApp)
- **Fontes**: Google Fonts (*Plus Jakarta Sans* e *Space Grotesk*)
- **Ícones**: Font Awesome 6
- **Deploy**: Hospedagem contínua via [Vercel](https://vercel.com) vinculada ao repositório GitHub.

## 🛠️ Como Personalizar

1. **Número do WhatsApp**: Altere a constante `COMPANY_PHONE` no arquivo `script.js` ou edite os links `wa.me/` diretamente no `index.html`.
2. **E-mail e Redes Sociais**: Ajuste os links do rodapé em `index.html`.

## 📦 Deploy na Vercel

O projeto está configurado para deploy automático na Vercel a cada `git push` na branch `main`.
